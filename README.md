# Hdtv

Android TV 直播 App。读取 M3U,自动按国家 / 类别分类,只保留直播。

- 播放源地址:`app/src/main/java/com/hdtv/live/Config.kt`
- 编译:推送到 GitHub 后,在 Actions → Build APK → Artifacts 下载 `Hdtv-apk`
- 打开 App 直接进入分类 / 频道列表:左右键切换分类和频道,确认键播放
- 播放中:上下键换台;短按确认键打开列表;按住确认键 3 秒收藏 / 取消收藏;返回键弹出「退出 / 继续观看」
- 列表里选中频道后按住确认键 3 秒,同样可以收藏;分类里有「★ 收藏」
